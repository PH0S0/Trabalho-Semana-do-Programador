Código morse no arduino (com luz e som) :

Neste tutorial, aprenderemos a criar um transmissor de Código Morse utilizando um LED (sinal visual) e um Buzzer (sinal sonoro) comandados em paralelo. O projeto emitirá a famosa mensagem de socorro internacional: o sinal de SOS (... --- ...).

Componentes Necessários:

  • 1 Placa Arduino (Uno, Nano ou compatível)
  • 1 Protoboard e Jumper de conexão
  • 1 LED (qualquer cor) e 1 Resistor de 220 Ohms
  • 1 Buzzer Ativo ou Passivo de 5V

Esquema de Ligação:

Conecte a perna positiva (maior) do LED em série com o resistor na **Porta Digital 13** do Arduino, e a perna negativa (menor) no pino **GND**. Em seguida, ligue o pino positivo do Buzzer também na **Porta Digital 13** (ou altere no código abaixo) e o negativo no pino **GND**.

Código de Programação (.ino):

const int pinoSinal = 13; // LED e Buzzer conectados no mesmo pino

void setup() {
  pinMode(pinoSinal, OUTPUT);
}

void loop() {
  // Letra S: Três pontos (...)
  emitirSinal(200); delay(200);
  emitirSinal(200); delay(200);
  emitirSinal(200); delay(600); // Intervalo entre letras

  // Letra O: Três traços (---)
  emitirSinal(600); delay(200);
  emitirSinal(600); delay(200);
  emitirSinal(600); delay(600); // Intervalo entre letras

  // Letra S: Três pontos (...)
  emitirSinal(200); delay(200);
  emitirSinal(200); delay(200);
  emitirSinal(200); delay(2000); // Intervalo longo para reiniciar o SOS
}

void emitirSinal(int duracao) {
  digitalWrite(pinoSinal, HIGH); // Liga luz e som
  delay(duracao);
  digitalWrite(pinoSinal, LOW);  // Desliga luz e som
}
