Como tocar músicas no arduino :

Neste tutorial, vamos aprender a utilizar a função nativa `tone()` do Arduino para gerar frequências sonoras específicas e criar melodias reais utilizando um Buzzer.

Componentes Necessários:

  • 1 Placa Arduino
  • 1 Buzzer (Ativo ou Passivo de 5V)
  • Jumpers de conexão

Esquema de Ligação:

A ligação é extremamente simples: conecte o pino positivo (+) do Buzzer na **Porta Digital 8** do Arduino, e o pino negativo (-) no pino **GND**.

Código de Programação (.ino):

O código abaixo define as frequências das notas musicais e toca a melodia clássica de "Brilha, Brilha Estrelinha":

// Definição das frequências das notas musicais
#define NOTE_C4 262 // Dó
#define NOTE_D4 294 // Ré
#define NOTE_E4 330 // Mí
#define NOTE_F4 349 // Fá
#define NOTE_G4 392 // Sol
#define NOTE_A4 440 // Lá

const int pinoBuzzer = 8; // Buzzer conectado no pino 8

// Notas da melodia (Brilha, Brilha Estrelinha)
int melodia[] = {
  NOTE_C4, NOTE_C4, NOTE_G4, NOTE_G4, NOTE_A4, NOTE_A4, NOTE_G4,
  NOTE_F4, NOTE_F4, NOTE_E4, NOTE_E4, NOTE_D4, NOTE_D4, NOTE_C4
};

// Duração de cada nota: 4 = semínima (tempo padrão)
int duracaoNotas[] = {
  4, 4, 4, 4, 4, 4, 2,
  4, 4, 4, 4, 4, 4, 2
};

void setup() {
  // Percorre as 14 notas da melodia
  for (int notaAtual = 0; notaAtual < 14; notaAtual++) {
    // Calcula a duração da nota em milissegundos
    int duracaoMs = 1000 / duracaoNotas[notaAtual];
    
    // Toca a nota no pino configurado
    tone(pinoBuzzer, melodia[notaAtual], duracaoMs);

    // Adiciona um pequeno intervalo entre as notas para distingui-las
    int intervalo = duracaoMs * 1.30;
    delay(intervalo);
    
    // Para o som antes da próxima nota
    noTone(pinoBuzzer);
  }
}

void loop() {
  // O código roda apenas uma vez no setup. 
  // Se quiser repetir, mova o bloco 'for' para cá.
}
